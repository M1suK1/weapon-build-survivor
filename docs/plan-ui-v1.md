## 1. 交互层总体设计

### 1.1 三层结构

```
常驻 HUD（不暂停）          一级界面（暂停）            二级界面（暂停，盖在前面）
├ 升级按钮 ★新             ├ 构筑屏                   ├ 装置面板 ★新
├ 武器栏（可点选中/开关）    │  ├ 左：电路板            ├ 配方详情 ★新
├ 顶部状态                 │  ├ 右：库存 / 配方 / 装置  └ 替换武器 ★已有
└ F3 调试                  └ 宝箱四选一 ★已有
```

- 一级界面同时只能开一个（已实现）。
- 二级界面从一级界面里「点某个对象」打开，返回后回到一级界面原状态（滚动位置、选中项都保留）。
- 二级界面统一返回方式：**右上角 `×` 按钮 / 左上角 `← 返回` / `ESC` / 鼠标右键**。四种都实现，防止玩家找不到出口。

### 1.2 鼠标规范（全局）

| 项 | 规则 |
| --- | --- |
| 可点元素最小尺寸 | 28×28 px（1280×720 基准），插槽 56×56 |
| hover | 元素加 1px 白边 + 亮度 +12%，鼠标变手型 |
| press | 缩放 0.96，松开回弹 |
| 禁用态 | 亮度 45%，鼠标默认箭头，hover 不变化，但仍显示 tooltip 说明缺什么 |
| tooltip | 悬停 0.35s 后出现在元素下方，内容：名称 / 数值 / 为什么不能操作 |
| 所有快捷键保留 | 鼠标是新增通道，键盘老玩家不受影响 |

### 1.3 关键风险：UI 坐标缩放

截图里 `pick_root.get_global_rect()` 是 `2560×1440`，而设计基准是 `1280×720` —— 说明画布被整体放大了 2×。拖拽/点击的坐标必须统一走 `get_global_mouse_position()` 和 `Control.get_global_rect()`，**不能假设 1:1**。这条要在 U1 先验证。

## 2. 构筑屏重做（对应第 1 条）

### 2.1 布局

左：电路板（不变，但每格变成可交互槽）。
右：三块内容用**标签页**切换，而不是现在这样竖排挤在一起。

```
[ 库存 ]  [ 配方 ]  [ 装置 ]
```

- **库存标签**：一行一个模块（色块 + 名称 + 阶 + 剩余寿命 + 当前出力），可拖拽。
- **配方标签**：只列已解锁；每行一个「合成」按钮（= 老的 C 键），材料不足时按钮禁用并写明缺几个。
- **装置标签**：每台一张小卡（编号 / 状态 / 进度条 / 正在做什么），点击进入装置面板（§4）。

### 2.2 槽位可交互

| 操作 | 结果 |
| --- | --- |
| 左键点空槽 | 自动放入「对整板出力增益最大」的模块（等价于现在的自动入槽，但只作用于这一格） |
| 左键点已占槽 | 选中该模块，显示它的数值与网络贡献（它给谁镜像、谁给它加成） |
| 悬停槽位 | 高亮**所有与它直接相连**的槽（1 格邻接用实线，共振/脉冲的影响范围用虚线） |
| 右键槽位 | 卸下，退回库存 |
| 拖拽 | 见 §3 |

### 2.3 武器栏

- 点击行 → 选中（当前编辑武器），行高亮。
- 行尾一个开关按钮（替代 `F`），一个「卸下武器」的小按钮（拖回背包）。
- 背包满时「卸下」按钮禁用 + tooltip 说明。

### 2.4 返回

构筑屏右上角 `×`、左上角 `← 返回战斗`、`ESC`、`TAB` 都能关。

## 3. 拖拽装模块（对应第 2 条）

### 3.1 拖拽源与落点

| 拖拽源 | 落点 | 行为 |
| --- | --- | --- |
| 库存模块 | 空槽 | 装入该格 |
| 库存模块 | 已占槽 | **交换**：槽内模块退回库存，新模块进槽（不做覆盖删除） |
| 库存模块 | 库存区 | 取消 |
| 槽内模块 | 另一槽 | 交换两格内容 |
| 槽内模块 | 库存区 | 卸下 |
| 槽内模块 | 板外 | 取消，弹回原位 |

### 3.2 拖拽时必须有预览

这是本作最核心的信息，不能只给一个跟手的图标：

- 拖拽中，板子上**每个合法落点**显示一个半透明预览框，框内写 `出力 12.4 → 38.9 (+26.5)`。
- 非法落点（比如把只对狙击枪生效的「多膛组」拖到冲锋枪板上）显示红叉 + 原因 `仅狙击枪可用`。
- 整板总出力在板子下方实时滚动：`单次出力 39.0 → 65.5`。
- 松手后如果出力**下降**，弹一个 0.6 秒的黄色提示条 `这次装配让出力下降 -3.2`（不阻止，玩家可以自己反悔）。

### 3.3 槽位方案（blueprint）—— 拖拽的真正意义

**这一节是 v1 初稿写错的地方。** 初稿写的是「手动摆放过的槽，寿命耗尽后锁自动解除」，那等于手动摆放只是一次性动作：模块 20~60 秒烧完，玩家就得重摆一遍 —— 那不是 build，那是劳动。正确的理解是：

> **手动摆放 = 为这个槽登记一套方案。方案永久有效，模块只是按方案流动的耗材。**

#### 3.3.1 方案是什么

- 每个槽有一个 `plan` 字段：记录**模块 id**（`base` / `add` / `amp` / `reson` / `multi` / `blade` …，id 决定效果类型与配方）。
- 槽的四种显示状态：

| 状态 | 含义 | 显示 |
| --- | --- | --- |
| 空 · 无方案 | 从没手动摆过 | 灰色虚线框 |
| 空 · 有方案但缺料 | 登记过方案，库存里没有这个 id | 红色 `缺 增幅`，方案图标保留 |
| 已装 · 有方案 | 方案正在生效 | 模块色块 + 右上角小锁 |
| 已装 · 无方案 | 自动入槽填的 | 模块色块，无锁 |

#### 3.3.2 补料规则（核心）

1. 槽内模块寿命耗尽 → 该格变空 → **当帧立刻**按 `plan` 从库存取同 id 模块补上。
2. 补料优先级：**有方案的槽先补**，然后才是无方案的自动槽。多个方案槽同时缺料时，按「剩余寿命 ÷ 总寿命」从小到大（快烧完的先补）。
3. 库存没有该 id → 槽进入「缺料」态（红色高亮），方案保留；之后掉落到同 id 会自动补上。
4. 若该 id 有配方、且构筑屏的「缺料自动下单」开着（默认开）：把该配方塞进第一台空闲装置，**产物直接进那个缺料槽**，不经过库存。
5. 「自动入槽」总开关（默认开）现在只影响**没有方案的空槽**是否自动填当前最优模块；有方案的槽永远按方案走。

#### 3.3.3 玩家怎么改方案

| 操作 | 结果 |
| --- | --- |
| 把库存模块拖到槽上 | 登记 / 改写该槽的 `plan`，并立刻装上 |
| 槽 ↔ 槽拖拽 | 交换两格的 `plan` 与当前模块 |
| 右键槽 | 清空 `plan`，槽回到「无方案」，模块退回库存 |
| 点小锁图标 | 同上（右键的鼠标等价物） |
| 悬停锁定槽 | 显示方案详情：该 id 的配方、库存还有几个、是否已自动下单 |

#### 3.3.4 为什么这样才对

- 模块是**弹药**，方案是**构筑**。玩家做的决定（哪格放增幅、哪格放共振、网络怎么连）应该长期生效，而不是每次烧完重来。
- 「模块有使用次数」的压力应该落在**产能**上（掉落 + 装置合成），而不是落在**点击次数**上。玩家要做的是扩建产线、调整配比。
- 这样 §4 的装置面板才变成真正的主循环：**方案缺什么 → 装置生产什么**。

### 3.4 实现要点（Godot 4）

- 库存行、槽位都用 `Control`，实现 `_get_drag_data` / `_can_drop_data` / `_drop_data`。
- `_get_drag_data` 返回 `{"from": "inv"/"slot", "id": mid, "slot": i, "preview": Control}`，`preview` 用一个 `Control` 画模块色块 + 名称。
- `_can_drop_data` 里算 `_board_total_with(mid, i)`，非法直接返回 false（Godot 会画禁止光标）。
- 拖拽结束统一走 `_apply_move(payload, target)` 一个函数，和键盘/点击路径共用，避免三套逻辑。

## 4. 合成装置界面（对应第 3 条）

### 4.1 入口

- 构筑屏「装置」标签页里点某台装置 → 打开装置面板。
- HUD 上不常驻装置状态（太吵），但装置全部空闲/全部忙碌时在构筑屏标签上显示 `3/3 空闲` 或 `3/3 忙碌`。

### 4.2 面板内容

```
┌─ 装置 #2 ─────────────────────────── × ─┐
│ 状态：空闲                              │
│ 当前配方：—                              │
│                                          │
│ 可选配方（只列已解锁 + 材料够）           │
│  ▸ 加法     2×基础   5s    [开始]        │
│  ▸ 锋锐刃   2×基础   5s    [开始]        │
│  ▸ 增幅     2×基础   8s    [开始]        │
│  （材料不够的配方不显示；已解锁但全不够  │
│    时显示一行灰字：材料不足 2 个基础）    │
└──────────────────────────────────────────┘
```

- 「材料不够的配方不显示」是你明确要求的；为了不让玩家以为没解锁，底部用一行灰字说明「还有 N 个配方材料不足」。
- 忙碌中打开面板：显示进度条 + `剩余 3.4s` + `[取消]`（取消返还全部材料，已消耗的时间不退）。

### 4.3 装置与背包

- 装置仍占背包格（你之前定的共享 6 格），面板顶部显示 `背包 4/6`。
- 新造装置后自动打开它的面板（省一次点击）。

### 4.4 快捷通道保留

- `C` = 把配方列表里第一个可用的塞进第一台空闲装置（老玩家连按 C 的节奏不变）。
- `X` = 造装置。

| HUD 左下常驻按钮 | 一颗圆形「↑ 升级」按钮，平时灰；材料够时变金色 + 1.2s 呼吸光 + 轻微上下浮动 |

## 8. 需要你拍板的点（我先给倾向）

1. **拖到已占槽 = 交换还是覆盖？** 倾向交换（不会误删高阶模块），代价是拖拽路径多一步。
2. **自动入槽默认开还是关？** 倾向默认开（新手不至于空板），它只影响「没有方案的空槽」。
3. **方案槽缺料时**：默认只认同一个 id（缺增幅就等增幅，不会偷偷换成加法）。代价是缺料时会空一格出力。要不要提供「允许降阶替代」（共振→增幅→加法 逐级降）？倾向**不做**，改用「缺料自动下单」解决，理由：偷偷换模块会让玩家看不懂自己的板子为什么变了。
4. **「缺料自动下单」默认开还是关？** 倾向默认开，但只对已有配方的 id 生效，且不抢占「玩家手动在装置里指定的配方」—— 手动指定优先。
5. **装置面板里「材料不够的配方完全不显示」** 会让人不知道还有哪些配方存在。倾向：不显示 + 底部一行「还有 N 个配方材料不足」。
6. **卸下武器**：现在没有这个操作，要不要加？（加了要处理背包格释放与当前选中武器被删）
7. **二级界面是否也支持拖拽**（把库存模块拖到装置上 = 喂材料）？倾向 U3 先不做，U4 看手感再加。
