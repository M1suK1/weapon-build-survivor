# Weapon Build Survivor

类《吸血鬼幸存者》的增量游戏：战斗靠走位与**搜寻目标自动开火**，成长靠**把模块插进武器的电路板**。

模块既是数值也是弹药 —— 每开一次火就烧掉每个模块 1 次使用次数，用完就消失。所以「堆高数值」和「撑住消耗」是同一件事的两面。

> 方案 v5（装填分层 / 方案草稿 / 拆卸销毁 / 升级曲线 / 敌人数拆分 / 宝箱放弃 / 多扇叶环绕刃 / 弹射与榴弹必爆 / 25 模块科技树 / buff 变体）与方案 v6（升级卡修复 / 输入冲突 / 曲线与自动升级 / 空模板 / 装置背包与升级 / 输出节奏 / UI 重排 / 激光环全屏 / 冲锋枪射程 / 敌人血量）已全部实现，过程见 [`docs/plan-v6.md`](docs/plan-v6.md) 与 [`docs/testlog.md`](docs/testlog.md)。下面描述的是当前代码的实际状态。

## 核心循环

**战斗层**：走位、别被围住。每把启用的武器按自己的间隔自动开火，开火时**搜寻射程内最近的 N 个目标**各结算一次伤害；射程内没目标就不开火、不消耗次数（环绕刃空转也烧，榴弹炮空放也炸）。

**构筑层**（TAB 暂停）：敌人死亡掉基础模块 → 合成/拾取都**先落进库存** → 自己决定插进电路板哪一格 → 提供数值 → 被开火烧掉 → 逼你重新插。多余的模块拿去合成（2 个同族上一阶 → 1 个更高阶）或升级。

**为什么模块要有寿命**：如果模块永久，游戏就退化成「堆数字」。有了使用次数，短开火间隔 = 同样 DPS、双倍弹药消耗，开火间隔从手感参数变成弹药效率杠杆。所以「自动装填」被拆成玩家自己的决定：合成/拾取不再偷偷改板，但你可以开「自动补料」只解决「烧空之后」这一件事。

三条防止死亡螺旋失控的保底：

- **无目标不开火** —— 清场间隙不烧弹药
- **武器基础伤害** —— 模块烧光时 DPS 不归零，还有 `基础伤害 / 间隔` 可以蹭
- **受击补偿** —— 每损失 8 HP 补 1 个模块，掉在脚边被吸走（wave≥12 给加法，≥24 一次给 2 个）

## 运行

需要 Godot 4.7+。仓库里不带引擎，自行下载便携版放到 `.tools/godot/`（该目录已 gitignore）。

```powershell
# 直接运行
.\.tools\godot\Godot_v4.7.2-stable_win64.exe --path .
```

Windows 下如果报 `Could not create directory: 'user://logs'`，先设 `$env:APPDATA = (Get-Location).Path + "\.tools\appdata"`；`Failed to read the root certificate store.` 是无害噪音。

## 模块网络规则

相邻 = 网格**曼哈顿距离 1**（上下左右，不含斜角）。结算顺序固定：**共振 → 加法镜像 → 增幅加成**，且镜像**不连锁传播**。

| 模块 | 基础值 | 次数 | 网络效果 |
| --- | --- | --- | --- |
| 基础 T1 | 1.0 | 45 | 无。原料，也是唯一能被镜像的底层 |
| 加法 T2 | 3.0 | 60 | 自身 + 每个**相邻低阶**模块的基础值 |
| 增幅 T3 | 0 | 120 | 自身不出力，把 **5.0** 加到**所有相邻非增幅模块的最终输出**上 |
| 共振 T4 | 27.0 | 100 | 每个**相邻同阶（T4）**模块 +50% 基础值，可被多个共振叠加 |

- 加法的镜像是「读数」，不连锁，不会指数爆炸。
- 增幅加在**最终输出**上，不会被加法镜像放大；放在枢纽位最值钱。
- 其它 21 个模块按 7 个族排成科技树（锐化 / 冷却 / 弹链 / 穿甲 / 覆盖 / 维持 / 特化），合成下一件要吃同族上一件，详见 [`docs/reference.md`](docs/reference.md) §3。

```powershell
# 静态检查（改完代码至少跑这个；成功时只有一行版本号）
$env:APPDATA = ".tools\appdata"
cmd /c ".\.tools\godot\Godot_v4.7.2-stable_win64.exe --headless --path . --check-only --script res://scripts/game.gd & echo EXIT=%ERRORLEVEL%"

# 电路板规则：期望 out=[40.5, 45.5, 0.0, 1.0, 5.0, 6.0] power=100.0
.\.tools\godot\Godot_v4.7.2-stable_win64_console.exe --headless --path . -- boardtest
```

GDScript 报 `Parse Error` 时 Godot 只往 stderr 打一行、然后像没事一样退出；排查时**别加 `2>$null`**。

## 已知问题

- 敌人没有寻路，直线冲脸，会互相重叠成一条线
- 屏幕外敌人不做剔除，靠 `MAX_ENEMIES = 400`（普通 250 + 重装 150）硬 cap
- 重装变种抽到 shooter 模板时会风筝，和「拦路」定位相反
- 模块背包容量 6：只装武器与模块（装置有自己的背包），宝箱界面满时会走「替换」
- 构筑屏是固定布局，UI 缩放没做适配（只验证过 1280×720）
- 激光环的「全场」判定已经能用（`targets = -1`），但视觉还是普通弹道，没有环状冲击波
- buff 的「同品质降级补位」是按任意品质兜底，不是严格的相邻档降级
